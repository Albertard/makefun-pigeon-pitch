# pigeon-pitch

A program that writes one original line — the elevator pitch a city pigeon
gives investors for its startup — to `/output/entry.txt`, the whole entry
for the make.fun competition **"Pigeon Pitch, One Line"**
(`u-donrulezz-pigeon-pitch-one-line-af06c6cf`).

## The line

> We're Uber for breadcrumbs: I deliver crumbs to every pigeon in the city in under five minutes, and our only churn is the hawks.

128 characters. The pigeon pitches like a founder — same-day delivery,
city-wide coverage, a unit-economics metaphor — then the churn line
reminds you the "customers" are prey. Startup jargon, pigeon voice, one
sting at the end.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
